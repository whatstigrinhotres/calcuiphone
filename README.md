# CALCUIPHONE

Calculadora web inspirada na calculadora do iPhone, feita para abrir no Safari e em outros navegadores móveis.

## Testar localmente

Abra `index.html` em um navegador.

## Publicar com GitHub Pages

1. Abra **Settings** neste repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
5. Aguarde a publicação. O endereço será `https://whatstigrinhotres.github.io/calcuiphone/`.

A interface foi dimensionada para telas móveis e usa o visual preto, cinza e laranja da calculadora do iPhone. Os tamanhos são proporcionais à tela; o navegador não permite controlar a barra de status nativa do iOS.
